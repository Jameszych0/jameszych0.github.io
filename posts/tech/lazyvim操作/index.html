常见模式 #

Normal #

用于处理文字 对于提示

  • tab、s tab 选择

Visual #

选择模式

Insert #

1.如何进入插入模式

  • i 在光标的前面进行插入

  • I 在句子的前面进行插入

  • a 在光标的后面进行插入

  • A 在句子的后面进行插入

  • o 在当前行的下一行进行插入

  • O 在当前行的上一行进行插入

  • gi 移动到上一次插入的地方

  • ctrl + R 打开寄存器 显示历史复制信息

Command #

Normal模式下输入:进入Command模式

常见命令

  • q
  • wq
  • q!
  • e 文件路径 打开文件

s模式 #

查找文本 s: 按s进入搜索模式，输入想要跳转到的字母进行跳转

滚动屏幕

  • ctrl + u 向上半个屏幕
  • ctrl + d 向上半个屏幕

z模式 #

光标位置、代码折叠、其他杂项

  • zz 当前行居中
  • zt 当前行置顶
  • zb 当前行置底

f模式 #

查找模式

  • f 向后搜索
  • F 向前搜索

lazyvim系统设置 #

基本文件操作 #

文件浏览器 #

space + e 打开文件浏览器

  • enter 打开/关闭文件夹

  • a: 添加文件/文件夹

  • d: 删除文件/文件夹

  • r: 重命名

  • tab: 多选

  • H: 打开隐藏的文件

  • spcae + f + f: 查找文本

  • ctrl + h/l: 在文件浏览器和文件中移动

  • ctrl + s: 将选中的文件向下分屏

  • ctrl + v: 将选中的文件向右分屏

文件Buffer #

  • + h/l: 在buffer中移动
  • + b + d: 删除该buffer
