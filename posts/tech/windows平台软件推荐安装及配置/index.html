clash #

clash vs. clash verge 机场：性价比机场 关闭系统代理，在对应软件设置代理

  • chrome

    • 插件：Proxy SwitchyOmega 3 (ZeroOmega)

  • typora

  • powershell

    • echo $profile 找到powershell的配置文件，写入：
    function proxy {
    $env:http_proxy = "http://127.0.0.1:7890"
    $env:https_proxy = "http://127.0.0.1:7890"
    [System.Net.WebRequest]::DefaultWebProxy = New-Object System.Net.WebProxy("http://127.0.0.1:7890")
    Write-Host "Proxy enabled: http://127.0.0.1:7890" -ForegroundColor Green
}

function unproxy {
    $env:http_proxy = $null
    $env:https_proxy = $null
    [System.Net.WebRequest]::DefaultWebProxy = $null
    Write-Host "Proxy disabled" -ForegroundColor Yellow
}

function check-proxy {
    if ($env:http_proxy -or $env:https_proxy) {
        Write-Host "Current proxy settings:" -ForegroundColor Cyan
        Write-Host "HTTP Proxy: $env:http_proxy"
        Write-Host "HTTPS Proxy: $env:https_proxy"
    } else {
        Write-Host "No proxy is currently set." -ForegroundColor Cyan
    }
}

开发环境 #

java #

  • java
  • navicat-premium-lite
  • another-redis-desktop-manager
  • apipost
  1. jdk下载
  2. 配置系统环境变量

    变量：JAVA_HOME 值：jdk的安装路径，例如E:\DevTools\Java\jdk-24

  3. 在系统环境变量Path后面追加

    %JAVA_HOME%\bin 注意：%JAVA_HOME%\bin要放到path最上面，因为JDK17安装的时候会默认添加一个环境变量而且在path中优先级比我们配置的高

或者，可以使用scoop进行jdk的安装管理

  1. 添加 Java bucket

    scoop bucket add java

  2. 安装不同版本的 JDK 比如安装 OpenJDK 17 和 21：

    scoop install openjdk17 scoop install openjdk21

  3. 查看已安装版本

    scoop list

  4. 切换默认版本（reset 命令） Scoop 默认会把安装的 app 链接到 ~/scoop/apps//current，你可以用 reset 来切换：

    scoop reset openjdk17 #或者 scoop reset openjdk21

切换后，用 java -version 验证。

中间件 #

中间件最好通过服务器远程连接，下面提供一些docker安装命令

mysql

docker run --name dev-mysql -d \
-m 512M --memory-swap 1G \
-p 3306:3306 \
--restart always \
-v /usr/loca/data/mysql/conf:/etc/mysql/conf.d -e MYSQL_ROOT_PASSWORD=197803 mysql:5.7

redis

 docker run \
--name dev-redis \
-p 6379:6379 \
--restart unless-stopped \
-v ~/data/redis/data/data \
-v ~/data/redis/conf/redis.conf:/etc/redis/redis.conf \
-d redis:bullseye \
redis-server /etc/redis/redis.conf

minio 对象存储容器

docker run -p 9000:9000 -p 9090:9090 --name minio \
     -d --restart=always \
     -e "MINIO_ACCESS_KEY=minio" \
     -e "MINIO_SECRET_KEY=password" \
     -v ~/data/minio:/data \
     docker.m.daocloud.io/minio/minio server \
     /data --console-address ":9090" --address ":9000"
