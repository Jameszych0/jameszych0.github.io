2.wsl迁移至其他盘 #

迁移 #

（1）查看linux的NAME

wsl -l -v

（2）停止正在运行的wsl

wsl --shutdown

（3）将需要迁移的Linux进行导出

wsl --export NAME 需要迁移的位置(D:\ubuntu)

（4）导出完成后，将原有的Linux卸载

wsl --unregister NAME

（5）将导出的文件在其他盘进行导入

wsl --import NAME 需要导入的位置(D:\ubuntu)

（6）将该系统设置为默认系统

wslconfig /setdefault Name
如：wslconfig /setdefault Ubuntu-20.04

设置默认用户 #

进入新系统后，默认为root用户

（1）添加新用户

useradd 用户名

（2）为新用户添加权限

打开/etc/sudoers，添加以下四行中任意一条

youuser ALL=(ALL) ALL
%youuser ALL=(ALL) ALL
youuser ALL=(ALL) NOPASSWD: ALL
%youuser ALL=(ALL) NOPASSWD: ALL

（3）设置默认用户

打开/etc/wsl.conf，添加

[user]
default = NAME

4.代理 #

当我们在进行终端中下载python库或者git提交到仓库等操作时，可能会出现网络问题。配置代理可有效解决该问题。

将下面代码写入一个 bash 脚本.proxyrc，可以轻松的实现一键配置代理：

#!/bin/bash
host_ip=$(cat /etc/resolv.conf |grep "nameserver" |cut -f 2 -d " ")
export ALL_PROXY="http://$host_ip:7890"

脚本通过 cat /etc/resolv.conf 来获取 DNS 服务器，也就是 Windows 的 IP，再将其中的 IP 部分截取出来，加上代理客户端的端口（我的是 7890，可以根据自己实际情况修改），使用 export 写入环境变量中。

使用时只需要 source .proxyrc 就可以生效。

同时，代理工具要开启Allow LAN。
